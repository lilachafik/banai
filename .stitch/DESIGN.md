# Design System: "BanAI Material 3 — Oak" (Google Stitch)

- **Source:** Stitch project "BanAI Wardrobe Designer (Material 3)" (`projects/16300384723906330404`), design system `assets/5227635362972142746`, created 2026-10-16.
- **Guidelines:** Material Design 3 (m3.material.io). Replaces the earlier "Nordic Atelier" system (`projects/3881887321601714246`).
- **Reference screen:** [`m3-main-screen.png`](m3-main-screen.png), generated by Stitch from this design system.
- **Implementation:** vanilla CSS in `frontend/src/styles/{tokens,layout,controls}.css`.

## Intent
A professional, desktop-first furniture configurator. Calm tonal surfaces, a large central 3D canvas, and one warm oak accent. The UI chrome stays neutral so wardrobe materials keep their true colours in the viewer.

## Colour
- **Scheme:** M3 dynamic colour, **Tonal Spot**, light, seed **`#B4532A`** (oak).
- Roles are generated with `@material/material-color-utilities` (`SchemeTonalSpot`) and written into `tokens.css` as `--md-sys-color-*`. Regenerate them rather than editing by hand.
- Components use colour **roles** only, never raw hex.

| Role | Value | Used for |
|---|---|---|
| `primary` / `on-primary` | `#8E4C32` / `#FFFFFF` | Filled buttons, switch, selection outline and tag, focus ring |
| `secondary-container` / `on-…` | `#FFDBCE` / `#5D4035` | Tonal buttons, selected segment, selected list item |
| `surface` | `#FFF8F6` | App background, top app bar |
| `surface-container-low` | `#FFF1EC` | Side panes |
| `surface-container` | `#FCEAE4` | 3D viewer background |
| `surface-container-high` / `-highest` | `#F7E4DF` / `#F1DFD9` | Chat bubbles, proposal card |
| `surface-container-lowest` | `#FFFFFF` | Text fields, selected-component card, list items |
| `outline` / `outline-variant` | `#85736D` / `#D8C2BB` | Field borders / dividers |
| `error` / `error-container` | `#BA1A1A` / `#FFDAD6` | Validation messages, destructive actions, error banner |

**Elevation** comes from tonal surface containers, not shadows. **State layers:** hover 8%, focus and pressed 10%.

## Type
**Roboto Flex** (variable, self-hosted via `@fontsource-variable/roboto-flex`; no Google Fonts requests because of the CSP). M3 type scale tokens `--md-sys-typescale-*`:
- title-large: app title
- title-medium: pane titles
- label-large (uppercase, 1px tracking): section headers; also buttons
- title-small: sub-headers (e.g. "Carcass & interior")
- body-large: field values; body-medium: content; label-medium: field labels and 3D tags

Numbers use `tabular-nums`.

## Shape
M3 scale: extra-small 4px (text fields), small 8px (chips, dimension tags), medium 12px (cards, list items), large 16px, extra-large 28px, full (buttons, segmented buttons, switch, swatches, composer).

## Icons
Material Icons (Apache 2.0) as inline SVG symbols in `index.html` and a CSS mask for the check mark. No icon font, so no extra multi-MB download.

## Components

| Component | M3 spec | Class |
|---|---|---|
| Top app bar | Small, 64px, surface, bottom divider | `.topbar` |
| Text field | Outlined, dense 40px, unit suffix `cm`, numbers right-aligned, 2px primary focus, error role on `aria-invalid` | `.field__input`, `.field__suffix` |
| Buttons | Filled (primary), Tonal (default), Outlined, Text (ghost), Error-outlined (danger); full-round, 40px | `.btn--primary`, `.btn`, `.btn--outlined`, `.btn--ghost`, `.btn--danger` |
| Segmented button | Full-round outline; selected = secondary-container + check | `.segmented` |
| Switch | 52×32 track, handle grows when on | `.toggle input` (native checkbox, `role="switch"`) |
| Swatch | 40px circle; selected = 2px primary ring + check on a white disc | `.swatch` |
| List item | 56px, medium shape; selected = secondary-container | `.compartment-row` |
| Selected-component card | surface-container-lowest card with a primary dot header | `[data-testid="selected-section"]` |
| Chat | Bubbles, pill composer with filled send icon button | `.chat__*`, `.composer`, `.icon-btn` |
| Proposal card | Filled card: "Proposed changes", list, note "Nothing changes until you confirm", Filled **Confirm** + Outlined **Cancel**; stale banner in error-container | `#proposal-card-template` |
| 3D tags | Dimension tags = small outlined; selection tag = primary pill | `.dim-label`, `.dim-label--selected` |

## Phase 5 shell
The chat pane, composer and proposal card exist as **static, disabled markup** only. The composer is disabled and the proposal card is an inert `<template>`. Phase 5 wires them up.

## Deliberately not implemented
These parts of the Stitch screen are outside the agreed MVP scope or would add behaviour:
- **Front / Isometric / Top** camera presets, **zoom / reset** buttons and the camera-info chip in the viewer.
- **"V2 Draft"**, **"Ready"** and **"Live Inspector"** badges, and the help icon.
- The design system's font update failed in Stitch ("invalid argument"); the fonts are specified in its guidelines text and implemented here.
